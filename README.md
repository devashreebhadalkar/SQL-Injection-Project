# SQL Injection Security Dashboard

A DBMS project demonstrating SQL injection detection and secure login using Python, Flask, and SQLite.

## 🌐 Live Website

**[Open SQL Injection Security Dashboard](https://sql-injection-project-zytv.onrender.com/)**

## 💻 Source Code

[View this project on GitHub](https://github.com/devashreebhadalkar/SQL-Injection-Project)

## ✨ Features

- Flask-based web dashboard
- SQLite database integration
- Secure login using parameterized SQL queries
- SQL injection pattern detection
- Login validation and testing
- Educational vulnerable-login demonstration

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- Git and GitHub
- Render for deployment

## 🧪 Testing

The project includes tests for:
- Successful login with valid demo credentials
- Rejection of incorrect passwords
- Detection of suspicious SQL injection patterns
- Detection of `UNION SELECT` patterns

## ⚠️ Disclaimer

This project is intended for educational purposes only. Use fictional credentials and do not enter real or sensitive information.
